# BrandBuddy AI

**Multilingual AI-powered content studio for small businesses.**

BrandBuddy AI helps small businesses, clothing brands, restaurants, beauty businesses, and freelancers create marketing content efficiently.

## Features

- Generate marketing captions and product descriptions.
- Create content in English, Urdu, and Roman Urdu.
- Generate relevant hashtags and campaign ideas.
- Support multiple business niches.
- Provide a responsive, user-friendly interface.
